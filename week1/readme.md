# Week 1: Data Gathering, Cleaning, and Preprocessing

## Project Overview
This project focuses on collecting, exploring, cleaning, and preprocessing a publicly available dataset as part of the Data Science Internship Week 1 task.

## Dataset
- **Name:** Wine Recognition Dataset
- **Source:** UCI Machine Learning Repository
- **Records:** 178
- **Features:** 13 numerical features
- **Target:** 3 wine classes

## Data Preprocessing Steps
- Checked missing values and duplicate records
- Identified potential outliers using the IQR method
- Reviewed inconsistent and abnormal values
- Converted numerical columns to appropriate data types
- Converted the target variable into a categorical format
- Validated the cleaned dataset

## Files Included
- `Week1_Data_Preprocessing_Report.docx` – Detailed preprocessing report
- `cleaned_wine_dataset.csv` – Cleaned dataset

## Tools Used
Python, Pandas, NumPy, Scikit-learn

## Outcome
The dataset was cleaned, validated, and prepared for further exploratory data analysis and machine learning.
