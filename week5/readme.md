# Week 5: Data Visualization and Communication

## Project Overview
This project focuses on analyzing and communicating data insights through effective visualizations using the Wine Recognition dataset.

The objective is to understand patterns, distributions and relationships between different chemical features of wine samples.

## Dataset
- Dataset: Wine Recognition Dataset
- Source: UCI Machine Learning Repository / Scikit-learn
- Total Records: 178
- Numerical Features: 13
- Target Classes: 3

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Visualizations Created
1. Bar Chart – Distribution of wine classes.
2. Histogram – Alcohol distribution across wine classes.
3. Correlation Heatmap – Relationships between numerical features.
4. Boxplot – Color intensity distribution by wine class.
5. Correlation Analysis – Identification of strongly correlated features.

## Key Analysis
- Compared the number of observations in different wine classes.
- Analyzed alcohol distribution across classes.
- Identified relationships between chemical properties.
- Compared color intensity across wine categories.
- Used visualizations to communicate patterns and observations.

## Files Included

## Conclusion
This project demonstrates how data visualization can transform numerical data into meaningful insights. Different visualization techniques were selected according to the type of information being analyzed.
