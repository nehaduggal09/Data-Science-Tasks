# Week 6: Integrated Data Science Project

## Project Title
Wine Classification Using Data Science and Machine Learning

## Project Overview
This is an integrated Data Science project that combines data preprocessing, exploratory data analysis, statistical analysis, machine learning and data visualization.

The main objective is to classify wine samples into three categories using their chemical properties.

## Dataset
- Dataset: Wine Recognition Dataset
- Source: UCI Machine Learning Repository / Scikit-learn
- Total Records: 178
- Features: 13 numerical chemical properties
- Target Variable: Wine Class
- Number of Classes: 3

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- SciPy
- Jupyter Notebook

## Project Workflow

### 1. Data Collection and Preprocessing
- Loaded the public Wine Recognition dataset.
- Checked dataset dimensions, missing values and duplicate records.
- Prepared features and target labels.

### 2. Exploratory Data Analysis
- Analyzed feature distributions.
- Studied class distribution.
- Explored relationships between numerical features.

### 3. Statistical Analysis
- Applied One-Way ANOVA to compare alcohol measurements across the three wine classes.
- Calculated the F-statistic and p-value.

### 4. Machine Learning
- Implemented Logistic Regression and Random Forest.
- Split data into training and testing sets.
- Applied GridSearchCV and 5-fold cross-validation.
- Evaluated classification performance.

### 5. Data Visualization
- Created histograms.
- Generated correlation heatmaps.
- Created class distribution charts.
- Generated confusion matrix visualizations.

This project demonstrates an end-to-end Data Science workflow by combining data preparation, statistical analysis, machine learning and visualization to solve a classification problem.
