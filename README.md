# 📊 Data Science Internship – 6 Weeks Project

## 👩‍💻 Project Overview

This repository contains my work and practical learning throughout a 6-week Data Science Internship. During this internship, I worked on different stages of the Data Science lifecycle, including data preprocessing, exploratory data analysis, statistical analysis, machine learning, data visualization, and an integrated data science project.

The primary objective was to gain hands-on experience with Python-based data science tools and techniques and understand how to transform raw data into meaningful insights.

For consistency across the tasks, I used the publicly available **Wine Recognition Dataset**, which contains chemical measurements of wine samples belonging to three different classes.

## 🎯 Internship Objectives

- Understand and implement data preprocessing techniques.
- Perform Exploratory Data Analysis (EDA).
- Apply statistical methods and hypothesis testing.
- Develop and evaluate machine learning models.
- Create meaningful data visualizations.
- Integrate different data science techniques into a complete project.
- Improve analytical thinking and practical Python programming skills.

## 🗂️ Weekly Tasks

### Week 1: Data Collection and Preprocessing
- Selected and loaded a publicly available dataset.
- Explored the dataset structure and dimensions.
- Checked missing values and duplicate records.
- Performed data cleaning and preprocessing.
- Prepared the cleaned dataset for further analysis.

### Week 2: Exploratory Data Analysis (EDA)
- Performed descriptive statistical analysis.
- Calculated measures of central tendency and dispersion.
- Analyzed numerical feature distributions.
- Created histograms, scatter plots, boxplots, and correlation heatmaps.
- Identified patterns, relationships, and potential outliers.
- Performed statistical analysis where applicable.

### Week 3: Statistical Modeling and Hypothesis Testing
- Applied statistical techniques to understand relationships in the dataset.
- Formulated null and alternative hypotheses.
- Performed hypothesis testing.
- Calculated F-statistic and p-value using ANOVA.
- Interpreted statistical results and their significance.

### Week 4: Machine Learning Model Development and Evaluation
- Prepared training and testing datasets.
- Implemented Logistic Regression and Random Forest classification.
- Applied 5-fold cross-validation.
- Performed hyperparameter tuning using GridSearchCV.
- Evaluated models using accuracy, precision, recall, and F1-score.
- Generated a confusion matrix and analyzed model performance.

### Week 5: Data Visualization and Communication
- Created visualizations using Matplotlib and Seaborn.
- Analyzed class distribution and feature distributions.
- Created correlation heatmaps and boxplots.
- Identified important patterns and relationships.
- Communicated analytical findings through visual storytelling.

### Week 6: Integrated Data Science Project
- Combined data preprocessing, EDA, and statistical analysis.
- Applied machine learning algorithms.
- Performed model optimization and evaluation.
- Created visualizations to communicate findings.
- Prepared a comprehensive project report.
- Documented the complete data science workflow.
